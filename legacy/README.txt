Historical supplementary analysis code

SI_original.R is the earlier root-level SI.R, moved without changing its contents.
perm_plots.R was copied from the MSc research project and contains historical model
comparison and sample-size plotting. These scripts use placeholder or older paths
and saved R workspaces. They are retained for context and are not the revised entry
point. Their large experiment objects were not added to Git or LFS because the saved
spatPredict spatial pointers are not portable. The original objects are preserved
locally under MSc/data/permafrost/model optimization/.

Use R/permafrost/permafrost_model_revision.R for the maintained workflow.
